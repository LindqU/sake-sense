# 修正内容の確認 - マイページ機能の実装

ユーザーがプロフィール（表示名）やパスワードを更新できるマイページ機能を実装しました。

## 実装内容

### 1. サーバーアクション (`src/lib/auth-actions.ts`)
- `updateProfile`: `auth.updateUser` でユーザーメタデータを更新し、同時に `profiles` テーブルの `display_name` も更新するようにしました。
- `updatePassword`: ユーザーのパスワードを安全に更新するロジックを追加しました。

### 2. UIコンポーネント
- `MyPage.tsx` [NEW]: プロフィール編集とセキュリティ設定（パスワード変更）を行うための新しいビューを作成しました。
- `Header.tsx`: ログイン時にユーザーアイコンを表示し、クリックでマイページへ遷移できるようにしました。
- `page.tsx`: 全体のルーティングに `mypage` 状態を追加し、コンポーネントを表示するようにしました。

## 検証結果

### 動作確認済み項目
- [x] ログイン後、ヘッダーにユーザーアイコン（人型）が表示されること。
- [x] アイコンクリックでマイページが表示されること。
- [x] 表示名を変更し「保存」すると成功メッセージが表示されること。
- [x] 表示名変更後、履歴一覧の「投稿者名」が即座に反映されていること（Supabase Viewの連携確認）。
- [x] パスワードを6文字未満で入力した際にバリデーションエラーが出ること。
- [x] 「戻る」ボタンで履歴画面または入力画面に戻れること。

## 注意事項
- パスワード変更後も現在のセッションは維持されます。
- メールアドレスの変更機能は、Supabaseのメール確認プロセスが必要なため、今回のスコープからは除外しています。
