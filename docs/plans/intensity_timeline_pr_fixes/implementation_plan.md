# IntensityTimeline PR指摘修正 実装計画

PRで指摘された以下の2点を修正します。

1. **レイアウトの修正**: 縦軸ラベル（強・弱）の下端がキャンバスの下端と一致するように構造を調整します。
2. **ラベルテキストの修正**: 計画書との整合性を取るため、縦軸ラベルを「強」「弱」から「強い」「弱い」に変更します。

## 変更内容

### [IntensityTimeline コンポーネント]

#### [MODIFY] [IntensityTimeline.tsx](file:///home/lindq/develop/sake-sense/app/src/components/IntensityTimeline.tsx)

- レイアウト構造の変更：
    - 現在：`flex` (縦軸ラベル + `flex-1` (キャンバス + 横軸ラベル))
    - 修正後：`flex-1` ( `flex` (縦軸ラベル + キャンバス) + 横軸ラベル)
    - これにより、縦軸ラベルの高さがキャンバスのみに連動するようになります。
- 縦軸ラベルの文言変更：
    - `<span>強</span>` -> `<span>強い</span>`
    - `<span>弱</span>` -> `<span>弱い</span>`
