# PR指摘事項の修正計画

PR #5 で指摘された以下の項目を修正します。

## 修正内容

### 1. `MyPage.tsx` の修正
- **エラーハンドリングの強化**
    - `fetchUser` 内の `supabase.auth.getUser()` の結果をチェックし、エラー時は前の画面に戻る、またはエラーメッセージを表示するようにします。
- **型安全性の向上**
    - `catch (error: any)` を `catch (error: unknown)` に変更し、型ガードを使用するように修正します。
- **アクセシビリティ対応**
    - `label` 要素に `htmlFor` を、`input` 要素に `id` を追加して紐付けを行います。
- **フォーム送信の修正**
    - 保存ボタンとパスワード変更ボタンに `type="submit"` を明示的に指定します。

### 2. `auth-actions.ts` の修正
- **サーバークライアントの適正化**
    - サーバーアクション内でシングルトンの Supabase クライアントを使用している箇所を、`@supabase/ssr` の `createServerClient` を使用するように変更します。これにより、認証コンテキストが正しく処理されるようになります。

## 検証計画

### 自動テスト
- `npm run build` を実行し、型エラーがないことを確認します。

### 手動検証
- マイページを開き、ユーザー情報が正しく表示されることを確認します。
- 表示名の変更とパスワードの変更を試し、正常に処理されることを確認します。
- ブラウザのデベロッパーツール（アクセシビリティツリー）で、ラベルと入力項目が紐付いていることを確認します。
