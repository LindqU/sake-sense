# PR指摘事項の修正計画

PRレビューで指摘されたクラス名の競合、アクセシビリティの問題、およびフォーム送信のバグを修正します。

## 概要
1.  **クラス競合の解消**: `tailwind-merge` と `clsx` を導入し、`Card` および `Button` コンポーネントでクラス名が適切にマージされるようにします。
2.  **アクセシビリティの改善**: ログイン・サインアップフォームの `label` と `input` を `htmlFor` と `id` で正しく関連付けます。
3.  **フォーム送信バグの修正**: サインアップ/ログインの切り替えボタンに `type="button"` を明示し、意図しないフォーム送信を防ぎます。

## 提案される変更

### 依存関係とユーティリティ
- `app/package.json`: `tailwind-merge` と `clsx` を追加します。
- `app/src/lib/utils.ts [NEW]`: `cn` ヘルパー関数を定義します。

### コンポーネント
- `app/src/components/ui/Card.tsx`: `cn` を使用して `className` をマージするように変更します。
- `app/src/components/ui/Button.tsx`: `cn` を使用して `className` をマージするように変更します。また、`type` プロパティのデフォルト値を考慮します。

### 認証フォーム
- `app/src/components/Login.tsx`:
    - 各入力フィールド（User Name, Email, Password, Invite Key）に対応する `id` を付与し、`label` の `htmlFor` を設定します。
    - フォーム下部の「新規登録はこちら/ログイン」の切り替えボタンに `type="button"` を追加します。

## 検証プラン

### 手動確認
1.  **ビルド確認**: `npm run build` が通ることを確認。
2.  **動作確認**:
    - ログイン/サインアップの表示が崩れていないこと。
    - 切り替えボタンをクリックしたときにページがリロード（送信）されないこと。
    - ログイン・サインアップが正常に行えること。
3.  **アクセシビリティ確認**: ブラウザのデベロッパーツールで `label` と `input` が正しく紐付いていることを確認。
